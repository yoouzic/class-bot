# ASR 三变体真实录音评测

2026-11-02，用 9 月 16 日《马克思主义哲学与辩证法》课程讨论录音（2 小时 17 分，AAC 48kHz 立体声）对转写栈做了三变体全量对比。所有变体共用同一份生产分段（webrtcvad，320ms 静音结束、最长 60 秒，共 1238 段 / 7857 秒语音），同一台 RTX 5070（torch 2.14.1+cu130），同一套课程热词（125 条）与纠错表。

**本页没有人工标注参考文本，因此只声称差异与速度，不声称准确率。** 复现：

```
PYTHONPATH=src .venv/Scripts/python.exe scripts/eval_asr_variants.py --audio "<录音>" --out tmp/eval-asr-20261101 --device cuda
PYTHONPATH=src .venv/Scripts/python.exe scripts/analyze_asr_eval.py --dir tmp/eval-asr-20261101
```

## 变体说明

| 变体 | 含义 | 对应生产路径 |
|---|---|---|
| streaming | 流式分块解码（600ms 块） | 实时 partial |
| refine | 流式模型整段重解码 | 现有 `final_refinement`（旧精修） |
| offline | 离线 SeACo-Paraformer + ct-punc + 热词 | 新精修（本次已接入） |

## 速度（全量 7857 秒语音实测）

| 变体 | 耗时 | RTF |
|---|---|---|
| streaming | 1104 秒 | 0.141 |
| refine | 1501 秒 | 0.191 |
| **offline** | **284 秒** | **0.036** |

新精修比旧精修**快 5.3 倍**，比流式路径快 3.9 倍。段末精修的墙钟开销对 60 秒段约 2.2 秒，远低于队列过载阈值。

## 质量信号（无参考文本下的间接证据）

| 指标 | streaming | refine | offline |
|---|---|---|---|
| 空段数（有语音但没识别出文字） | 410 / 1238 | 407 / 1238 | **268 / 1238** |
| 课程热词命中总数 | 421 | 420 | **556** |
| 热词密度（每千字） | 13.1 | 13.0 | **15.1** |
| 转写总字数（含标点） | 32242 | 32326 | 36734 |
| 内容一致率（去标点，对 streaming） | — | 0.972 | 0.648 |

- 空段减少 142 段：流式路径对约三分之一语音段完全没吐字，离线路径把其中近三分之一救了回来（多为短促语句）。
- 热词密度提升 16%：SeACo 热词偏置真实生效，不是总字数变多的副产品。
- refine 与 streaming 一致率 0.972 再次印证：旧精修与流式是同一个模型、同一套错误分布，"精修"没有带来质变。

|---|---|---|---|

| 物质世界 | 5 | 5 | **6** |
| 物资世界（错写） | 1 | 1 | **0** |
| 唯物辨证（错写） | 0 | 0 | 0 |

样例（第 38 段，柏拉图"白马黑马"举例）：流式为"它是有恒的它白色的的黑黑的码以下的码"，离线为"它是有有的的是白白的马，马黑始的马底下的马"——关键对象恢复出来，但离线并非全面占优（同段"在世践上"反而把流式正确的"在实践上"写错）。错误类型有交换，不是单向改善。

## 纠错表观察

三个变体的转写结果中，`corrections.txt` 左侧错误写法出现 0 次（该录音的口音未触发表内条目，或热词已预防）。据此**暂不裁剪纠错表**：本录音无法证明哪些条目冗余，裁剪需要出现过失的录音来验证。

## 结论与后续

1. **新精修（offline）以更低成本产出更高术语命中**，作为生产默认（`CLASSBOT_ASR_REFINER=seaco`）的决策得到本次数据支持。
2. 流式 partial 路径保持不变——它的错字由段末精修在最终转写里纠正，正是本次架构的设计意图。
3. 遗留未知：离线解码在 60 秒强制切分的中断处偶有补全式幻觉（如"审合灯事项"）；无参考文本，整体准确率未声称。要闭环需要一段 10–15 分钟人工标注对齐 CER。
4. 评测基建留存：`scripts/eval_asr_variants.py`（跑三变体）、`scripts/analyze_asr_eval.py`（出对比指标），下次录音只需换 `--audio` 与 `--reference`。
