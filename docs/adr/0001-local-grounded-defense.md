# ADR 0001：本地资料驱动的线上答辩会话

状态：已采用。

场景以任意本地文件夹为资料库，不按课程或项目名称硬编码策略。答辩输入采用
用户选定播放设备的全部系统回放；会议软件本身不需要专用集成。课堂麦克风模式保留为显式选择。

解析、去重、关键词与 BGE 语义向量在本机执行。DeepSeek 继续生成回答，只发送当前问题和
命中片段；会议背景只用于本地检索。资料作为不可信引用文本，不作为执行指令。回答区分来源事实、推断与建议。

完整与均衡覆盖策略按场景保存。完整策略包含可解析 JSON/CSV 与临时目录中的实验材料，
允许较长首次计算；达到安全边界时终止构建。隐藏、敏感、依赖及链接仍排除，不能将完整策略
理解为 OCR、任意嵌入对象提取或内容级凭据识别。

全量向量采用内存映射批次和持久恢复状态。恢复身份包含源文件、模型、编码算法版本、解析器版本与实际有序
片段摘要。只有完整一致的快照可原子发布；中断不能替换上一次可用快照。恢复进度不是可检索成果。

保留单体桌面程序的部署形式，通过资料索引、模型资源、问题版本和音频入口的明确所有权约束
并发及内存，不引入远程向量数据库或按具体项目建立特例。
